# Sounds

`you-got-mail.oga` is the "You've got mail!" clip played when new mail
arrives.

- It is an AI-generated voice, not a human recording.
- Ogg Vorbis, mono, 48 kHz, just under one second, at about −16 LUFS.
- The short silence at the start is deliberate. An audio output waking
  from suspend, such as HDMI or Bluetooth, can cut off the first moment of
  a sound.

To play a different file, set `soundFile` in the widget settings.
